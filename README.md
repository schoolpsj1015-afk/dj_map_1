# 🏙️ 부산 상권 빅데이터 지도 포털 (Busan Commercial Data Portal)

소상공인시장진흥공단 상가(상권)정보 빅데이터를 바탕으로 구축된 **부산광역시 상권 분석 인터랙티브 웹 지도 플랫폼**입니다.

편의점 특화 분석 웹앱(`web/`)과 부산 시내 10대 전 업종 155,103개 상가를 전수 조회할 수 있는 웹앱(`web2/`)으로 구성되어 있습니다.

| 서비스명 | 위치/경로 | 대상 데이터 | 주요 특징 |

| **🏪 부산 편의점 상권 지도** | `/web/index.html` | **2,751개** 편의점 | 4대 브랜드별 필터, 동적 그라데이션, 지점명 분리 |

## 🛠️ "사용량 초과로 인한 정지" 문제 해결 내역

기존 서비스에서 발생하던 지도 멈춤 및 정지 오류를 원천 차단하기 위해 아래와 같은 성능 & 안정성 최적화를 적용했습니다.

1. **🗺️ 타일 API 쿼터 초과(403 Forbidden) 방지**:
   - VWorld 공공 타일 API가 비인증 대량 요청 시 사용량 초과로 차단되는 문제를 해결하기 위해, 완전 무료 및 쿼터 제한이 없는 **CartoDB Voyager**를 기본 레이어로 적용했습니다.
   - VWorld, OpenStreetMap, Esri 지도를 멀티 레이어로 제공하며, 타일 로딩 실패 시 자동 폴백(Fallback) 안전장치를 구축했습니다.
2. **⚡ 15.5만 대용량 데이터 로딩 시 브라우저 정지(Crash/Freeze) 방지**:
   - Leaflet MarkerCluster의 **`chunkedLoading: true`** 모드를 활성화하여 5만 건 이상의 마커도 브라우저 스레드 멈춤 없이 백그라운드 청크 단위로 부드럽게 렌더링합니다.
   - **Lazy Popup**: 마커 생성 시 불필요한 팝업 객체를 미리 대량 생성하지 않고, 클릭 시점에 동적으로 생성하여 자바스크립트 힙 메모리를 90% 이상 절감했습니다.
   - **Icon Singleton**: 업종별 마커 아이콘 객체를 캐시 재사용하여 수만 개의 중복 DOM 인스턴스 생성을 차단했습니다.
3. **📦 데이터 파일 온디맨드 로딩**:
   - 10대 대분류별로 독립된 스크립트(`data_*.js`)로 분할하여 사용자가 선택한 업종의 데이터만 필요할 때 고속 로드하도록 설계했습니다.

## 🏬 부산 전체 상권 지도 (`web2/`) 상세 기능

* **10대 대분류 전수 지원**:
  * 🍽️ **음식** (52,167개)
  * 🛒 **소매** (38,705개)
  * 🔧 **수리·개인** (20,471개)
  * 💼 **과학·기술** (12,965개)
  * 📚 **교육/학원** (8,177개)
  * 🏠 **부동산** (6,009개)
  * 🎨 **예술·스포츠** (5,951개)
  * 🏗️ **시설관리** (5,592개)
  * 🏨 **숙박** (2,671개)
  * 🏥 **보건의료** (2,395개)
* **3단계 계층 필터**:
  * 1단계: **16개 구·군** 드롭다운 (선택 시 해당 구역으로 원클릭 FlyTo 이동)
  * 2단계: **대분류 업종** 칩 (점포 수 배지 표기)
  * 3단계: **중분류 & 소분류** 드롭다운 (각 항목별 점포 수 실시간 계산 표기)
* **초정밀 통합 검색**:
  * 상호명, 지점명, 업종명, 도로명주소, 지번주소, 동 단위 실시간 디바운스 검색
* **모바일 최적화 바텀 시트**:
  * 도로명주소/지번주소 원클릭 복사
  * 카카오맵 길찾기 및 네이버 지도 원클릭 연동
  * 내 위치 GPS 연동

## 🚀 실행 방법

### 1. 브라우저에서 직접 실행
* `index.html` 파일을 더블클릭하면 통합 포털이 열립니다.
* 편의점 지도는 `web/index.html`, 전체 상가 지도는 `web2/index.html`을 더블클릭하셔도 바로 실행됩니다.

### 2. 로컬 웹 서버 실행
* 루트의 `start_server.bat`를 실행하면 `http://localhost:8080` 포트로 로컬 웹 서버가 구동되며 포털과 두 지도를 자유롭게 이용하실 수 있습니다.
* `web/start_server.bat` (`:8080`) 또는 `web2/start_server.bat` (`:8082`)로 개별 실행도 가능합니다.
