# 🏪 부산 편의점 상권 지도 (Busan Convenience Store Map)

소상공인시장진흥공단 상가(상권)정보 빅데이터를 바탕으로 부산광역시 내 2,751개 편의점의 위치, 브랜드, 도로명 및 지번 주소를 시각화한 반응형 인터랙티브 웹 지도입니다.

---

## 🌟 주요 특징 (Key Features)

* **🗺️ 완전 무료 지도 API (국토교통부 VWorld + Leaflet)**
  * 유료 API 키나 워터마크 없이 깨끗한 국토교통부 표준 정밀 지도로 부산 전역을 탐색할 수 있습니다.
  * 2,751개 점포 데이터를 모바일 및 데스크톱에서 끊김 없이 부드럽게 렌더링하도록 **마커 클러스터링(MarkerCluster)**을 적용했습니다.
* **🎨 동적 브랜드별 고채도 파스텔 그라데이션**
  * 선택한 브랜드 조합에 따라 목록 배경이 은은하고 생동감 넘치게 실시간 블렌딩됩니다.
  * `CU + GS25`: 보라 + 파랑 135도 대각선 그라데이션
  * 전체 선택 시: 4대 편의점(CU ➔ GS25 ➔ 세븐일레븐 ➔ 이마트24) 고채도 멀티 그라데이션
* **🏷️ 직관적인 플랫 태그 시스템**
  * `1. 브랜드` (CU, GS25, 세븐일레븐, 이마트24, 개인·기타)
  * `2. 지점명` (해당 점포의 지점 정보 분리 표기)
  * `3. 지역` (시군구명 및 행정동명)
* **🔍 초정밀 통합 검색 & 분류 필터**
  * 상호명, 지점명, 도로명주소, 지번주소, 법정동/행정동 실시간 검색 지원
  * 부산 16개 구·군별 원클릭 시점 이동(FlyTo)
* **📱 모바일 최적화 반응형 레이아웃**
  * 상단 플로팅 검색바, 터치 슬라이드 드로어, 마커 클릭 시 스와이프 가능한 바텀 시트(Bottom Sheet) 제공
  * 도로명/지번 원클릭 주소 복사 및 카카오맵·네이버 지도 길찾기 연동

│   ├── index.html        # 메인 웹 페이지
│   ├── style.css         # 모바일 반응형 및 브랜드 스타일

│   └── start_server.bat  # 로컬 웹 서버 실행기

---

## 🚀 실행 방법 (How to Run)

1. **로컬 바로 실행**:
   * `web/index.html` 또는 `Data/map_preview.html` 파일을 더블클릭하여 브라우저에서 바로 열 수 있습니다.
2. **로컬 웹서버 실행**:
   * `web/start_server.bat`를 실행하면 `http://localhost:8080` 포트로 로컬 서버가 시작됩니다.
